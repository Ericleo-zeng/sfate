# scalable-fate (sfate)

A Schur-free absorption-probability solver for annotation-defined target states on latent-space kNN graphs.

## Install

```bash
pip install -e .
```

## Quick start

```python
import numpy as np
from sfate import build_transition_graph, absorption_probabilities

# X: (n_cells, n_latent) float32 latent representation
X = np.load("latent.npy").astype("float32")
P = build_transition_graph(X, k=30, random_state=20260909)

# labels: length-n array; each unique non-null label defines an absorbing class
labels = ...
B, info = absorption_probabilities(P, labels, r=30)
# B: (n_cells, n_classes) fate probability matrix
```

## Reproduce the paper results

Synthetic fixtures and benchmark fixtures are generated by the scripts:

```bash
# Generate the 5k fixture from public source data (manual data preparation required)
python scripts/make_fixture.py

# 5k validation certificate (four-value table)
python scripts/cert_recompute_5k.py

# Representative-count and kNN-k sensitivity
python scripts/exp_rep_sensitivity_v2.py
python scripts/exp_knn_k_sensitivity_v2.py

# Sign-permutation test for sample-level direction agreement
python scripts/exp_signflip_sign_agreement.py

# Convergence LMM
python scripts/analyze_convergence_lmm.py

# Latent-representation sensitivity (requires locally prepared source atlas)
SFATE_SOURCE_H5AD=/path/to/adata_annotated.h5ad python scripts/exp_latent_sensitivity.py

# Representative-selection sensitivity (centroid-nearest vs random-30 x 10 seeds)
python scripts/exp_rep_selection_sensitivity.py
```

`scripts/benchmark_m1_smoke.py` contains the in-script synthetic generators used for the scaling and smoke benchmarks.

## Data

The real-data case uses 74,984 forebrain microglia from a mouse 5xFAD/Cd28-cKO study (Ayata et al., 2025). Raw and source data are available through GEO accession **GSE296768**. The processed scVI latent representation and cell-type annotations are not bundled in this repository; they must be prepared locally before running the real-data scripts. See `scripts/make_fixture.py` for the expected input layout.
